# Blank Canvas — Faceplate Build Kit starter

Copy this whole folder:

```
cp -R public/skins/_blank public/skins/my-kit-skin
```

Then:

1. Edit `skin.json` — change `id`, `name`, `author`
2. Replace the PNGs with your art (same filenames)
3. Add your pack to `public/skins/index.json`
4. Reload Thrash Tracker / Datamoshpit and pick your pack on the LIVE screen

See [`docs/FACEPLATE_BUILD_KIT.md`](../../../docs/FACEPLATE_BUILD_KIT.md) for the full artist guide.
