# NODEMAP & EPISTEMIC STANCE

## NODEMAP

Modular visual node/tree builder for notes, projects, tasks, workflows, mind maps, and research organizing.

- Default: black/white hard-edged nodes, white wires
- **SHIFT pad (lower-left)** for left-hand edit mode; keyboard SHIFT+click also works
- Maps persist in `localStorage` (`kos.nodemap.project.v1`)
- Influenced by Dylan Louis Monroe (https://dsmp.io) — original tool; no DSMP assets

## EPISTEMIC STANCE

**Separate** desktop app (icon `¶`). Full readable method text for contested research. Not embedded in NODEMAP.

Free PDFs: https://dsmp.io/product-category/downloads/

## Desktop registration

- Icons in `src/components/os/Desktop.tsx`: NODEMAP `◈`, EPISTEMIC STANCE `¶`
- Shell wiring in `src/app/page.tsx`
