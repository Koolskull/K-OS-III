## Epistemic stance (mapping)

This track uses the repo’s verification labels alongside common alternatives:

| This track | Flow‑state report | Meaning |
|---|---|---|
| VERIFIED | DOCUMENTED | Primary or two independents |
| SUPPORTED | — | One reliable source |
| HAGIOGRAPHY | — | A Life/tradition attests it |
| CONTESTED | CONTESTED | Named scholars disagree |
| CLAIMED | UNSUPPORTED (as used there) | Anecdote/retelling without check |
| UNVERIFIED | — | Searched; not found |
| CONTRADICTED | — | Reliable sources say otherwise |
| NOT ADJUDICATED | AUTHOR’S INFERENCE / OWNER’S FRAME | Intentionally left open or labeled as a frame |

Medium tags: primary document · critical edition · translation (translator named) · liturgical text · secondary scholarship · official · press · fan · machine transcript · 🗣️ owner dictation.

Guardrails:
- Distinguish the biblical moral “fool” from the holy fool who assumes the world’s verdict.
- Mark formal status for each figure (glorified fool / framed / not a fool).
- Never diagnose historical persons in the track’s voice; handle mental‑illness readings respectfully.
- Never glorify self‑harm or provoked death; include safety notes in lessons 01 and 05 (and in the `endurance-and-love-log` tool).
