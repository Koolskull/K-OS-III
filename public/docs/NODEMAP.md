# NODEMAP & EPISTEMIC STANCE

## NODEMAP

Modular visual node/tree builder for notes, projects, tasks, workflows, mind maps, and research.

### Features
- Default black/white hard-edged nodes; white wires
- **Accurate hit-testing** in world space (stable when the window resizes; supports rotated nodes)
- **Compact SHIFT pad** (lower-left) + keyboard SHIFT for style/title edit
- **Pinch-to-zoom** on touch + mouse wheel zoom (anchored)
- **Node rotation** (−180…180°) in the edit panel
- **Wire routing slider**: straight → smooth cubic → orthogonal circuit grid
- Maps persist in `localStorage` (`kos.nodemap.project.v1`)

### Influence
Influenced by Dylan Louis Monroe (https://dsmp.io) — original tool; no DSMP assets.
